# AI Task Planner

## Problem
Turns a goal into a clear, editable task plan.

## Users
Students and freelancers who struggle to plan big goals.

## MVP Features
- [ ] Register / Login
- [ ] Create a goal with deadline
- [ ] AI generates a task preview
- [ ] Save plan
- [ ] Edit / delete tasks
- [ ] Mark task as done

## Later
- Reminders
- Drag and drop board
- Export to PDF

## Tech Stack
Angular, .NET Web API, SQL Server, Gemini/Groq (free tier)

## User Flow
Login → Goal → Generate → Preview → Save → Task list
